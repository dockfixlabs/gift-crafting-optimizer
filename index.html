Crafting success

success_rate = sum(craft_chance_permille) of 1-4 inputs (permille). UI % = floor((sum + 5) / 10), clamped 0-100. Probability = min(sum/1000, 1.0). All inputs are burned on attempt.

Attribute persistence

Use stargifts_craft_attribute_permilles (client config): array of 4 rows; row N has N+1 integers (permille). For k inputs, use row k-1. Group pattern/backdrop attributes by ID; for a group of size m, persistence = row[m-1] / 1000.

Key distinction

craft_chance_permille = per-gift success contribution. stargifts_craft_attribute_permilles = attribute persistence config. These are different fields and are not conflated.

Data access

Bot API has NO gift-craft methods. MTProto (user session) provides craft fields. This tool runs client-side on user-provided data only.
